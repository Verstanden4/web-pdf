# Web PDF Tools

A comprehensive collection of web-based PDF manipulation tools. This project provides various functionalities to work with PDF files and other document formats directly in the browser.

## Features

This project includes a wide range of tools:
- **Conversions to PDF**: HTML to PDF, JPG to PDF, PPT to PDF, Word to PDF, Excel to PDF.
- **Conversions from PDF**: PDF to Word, PDF to Excel, PDF to JPG, PDF to PPT, PDF to Markdown, PDF to PDF/A.
- **PDF Manipulation**: Merge, Split, Rotate, Crop, Organize, Remove Pages, Add Page Numbers.
- **Security & Privacy**: Protect (Encrypt), Unlock (Decrypt), Redact, Watermark, Sign.
- **Utility**: Compress, Extract, Repair, OCR (Optical Character Recognition), Compare, AI analysis.

## Tech Stack

Built with plain HTML, CSS, and JavaScript, leveraging powerful libraries including:
- `pdf.js` & `pdf-lib` for PDF manipulation
- `html2pdf.js` for HTML to PDF rendering
- `jszip` for handling zipped archives
- `tesseract.js` for OCR capabilities
- `xlsx` for Excel operations
- `pptxgen` for PowerPoint generation
- `mammoth` for Word document processing

## Getting Started

Simply open `index.html` in your preferred web browser to access the PDF tools interface locally. No server installation is required for most client-side operations.
